# Launch Files

## 1. `psm_bringup.launch.py`

This launch file initializes the Patient Side Manipulator (PSM) robot simulation with ROS 2 controllers, suitable for simulation and integration with other ROS 2 nodes.

### Purpose

-   Launches the robot description and state publisher.
-   Generates and loads the controller configuration.
-   Starts the ROS 2 control node with the specified controllers.
-   Spawns the joint state broadcaster and position controllers.
-   Runs a custom joint controller node for the PSM.
-   Launches RViz 2 with a pre-configured view.

### Nodes Launched

1. **Robot State Publisher (`robot_state_publisher`)**

    - Publishes the robot's state based on the URDF description.
    - Parameters:
        - `robot_description`: The robot's URDF model.
        - `publish_robot_description`: `True`
        - `use_sim_time`: `True`

2. **Controller Manager (`ros2_control_node`)**

    - Manages the controllers for the robot using the ROS 2 control framework.
    - Parameters:
        - Controller configuration from dynamically generated YAML file.
        - `use_sim_time`: `True`

3. **Joint State Broadcaster (`joint_state_broadcaster`)**

    - Publishes the state of all joints in the robot.
    - Loaded via the `spawner` executable.
    - Parameters:
        - `use_sim_time`: `True`

4. **Forward Position Controller (`forward_position_controller`)**

    - Controls the positions of the robot's joints.
    - Loaded via the `spawner` executable.

5. **Custom Joint Controller (`psm_joint_controller`)**

    - A custom node specific to controlling the PSM joints.
    - Parameters:
        - `use_sim_time`: `True`

6. **RViz 2 (`rviz2`)**
    - Visualizes the robot in a 3D environment.
    - Launches after the joint state broadcaster has started.
    - Uses a pre-configured RViz configuration file [psm_description.rviz](../rviz/psm_description.rviz).

### Configuration Files

-   **Robot Description (URDF Xacro files)**

    -   Located in the `urdf` directory.
    -   Defines the robot's physical and visual properties using Xacro macros.

-   **Controller Configuration**
    -   Dynamically generated by the [generate_controller.py](../scripts/generate_controller.py) script.
    -   Specifies the controllers to be loaded and their parameters.

### Usage

To launch the PSM robot with controllers:

```bash
ros2 launch psm_description psm_bringup.launch.py urdf:=<urdf_file> tool:=<tool_name>
```

Where:

-   `<urdf_file>` is the name of the URDF Xacro file (default: "psm.classic.urdf.xacro")
-   `<tool_name>` is the name of the tool to use (default: "sca", choices: "blade", "caudier_blade", "caudier", "sca_blade", "sca", "snake", "P420006", "SF826001")

### File Contents

-   **Launch File:** [psm_bringup.launch.py](psm_bringup.launch.py)
-   **RViz Configuration:** [psm_description.rviz](../rviz/psm_description.rviz)
-   **Custom Joint Controller Source:** [psm_joint_controller.cpp](../src/psm_joint_controller.cpp)
-   **Controller Configuration Generator:** [generate_controller.py](../scripts/generate_controller.py)

## 2. `view_robot.launch.py`

This launch file allows you to visualize the PSM robot and manually manipulate its joints using a GUI.

### Purpose

-   Launches the robot description and state publisher.
-   Starts the Joint State Publisher GUI for manual joint control.
-   Launches RViz 2 with a pre-configured view.

### Nodes Launched

1. **Robot State Publisher (`robot_state_publisher`)**

    - Publishes the robot's state based on the URDF description.
    - Parameters:
        - `robot_description`: The robot's URDF model.

2. **Joint State Publisher GUI (`joint_state_publisher_gui`)**

    - Provides a graphical interface to manipulate the robot's joint states.
    - Allows you to adjust joint angles and see the effect in real-time.

3. **RViz 2 (`rviz2`)**
    - Visualizes the robot in a 3D environment.
    - Uses the pre-configured RViz configuration file [psm_description.rviz](../rviz/psm_description.rviz).

### Configuration Files

-   **Robot Description (URDF Xacro files)**

    -   Located in the `urdf` directory.
    -   Defines the robot's physical and visual properties using Xacro macros.

-   **RViz Configuration (`psm_description.rviz`)**
    -   Located at [rviz/psm_description.rviz](../rviz/psm_description.rviz).

### Usage

To visualize the PSM robot and manipulate joints via GUI:

```bash
ros2 launch psm_description view_robot.launch.py urdf:=<urdf_file> tool:=<tool_name>
```

Where:

-   `<urdf_file>` is the name of the URDF Xacro file
-   `<tool_name>` is the name of the tool to use (default: "sca", choices: "blade", "caudier_blade", "caudier", "sca_blade", "sca", "snake", "P420006", "SF826001")

### File Contents

-   **Launch File:** [view_robot.launch.py](view_robot.launch.py)

---

### Additional Notes

-   Both launch files support different PSM configurations through the `urdf` and `tool` arguments.
-   The `psm_bringup.launch.py` file includes a dynamic controller configuration generation step, which allows for flexible setup based on the selected robot configuration.
-   The package includes various URDF Xacro files for different PSM configurations (Classic and Si versions) and tools, located in the `urdf` directory.
-   Mesh files for different PSM configurations and tools are stored in the `meshes` directory.
